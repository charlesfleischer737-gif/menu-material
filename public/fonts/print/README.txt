Print-ready static instances of the bundled DM Sans and Cormorant Garamond fonts.
Generated with fonttools 4.65.0 by scripts/prepare-print-fonts.py.
DM Sans: weight 600, optical size 24. Cormorant Garamond: weight 600.
Both retain the SIL Open Font License: see ../social/dmsans-OFL.txt and ../social/cormorantgaramond-OFL.txt.
PDF exports embed these complete static fonts with optional ligatures disabled, preserving visible glyphs and searchable text.
